Data Schema Reference
Both databases live in the same MySQL schema (boxgra5_cali). You will query them
individually and join them via shared fields such as ListingKey / L_ListingID, city, postal code,
and coordinates. Understanding the schema deeply is fundamental to every week in this
program.

Key Join Pattern
To correlate active listings with sold comps: JOIN rets_property r ON CAST(r.L_ListingID AS
UNSIGNED) = cs.ListingKey — or match on city + postal code for market-level analysis.
